================================================================================
FLINK TIME & WORKFORCE PLATFORM — STABILIZED CORE SETUP GUIDE
================================================================================

IMPORTANT
--------------------------------------------------------------------------------
This stabilization branch intentionally removes the legacy Code.gs backend and
bundled legacy admin_ui.html from the deployable Apps Script project.

Deploy ONLY the modern App.gs API and service files in this folder.

STEP 1: CREATE GOOGLE SPREADSHEET (MASTER CONTROL)
--------------------------------------------------------------------------------
1. Open Google Sheets at https://sheets.new and title it:
   "FLINK_Time_Master_Control"
2. Go to Extensions > Apps Script.

STEP 2: UPLOAD BACKEND SCRIPTS & HTML
--------------------------------------------------------------------------------
In the Apps Script editor, create/paste the .gs files from this folder,
including App.gs and all modern service/repository/schema files.

Do NOT add the legacy Code.gs file from older releases.
Do NOT add the legacy admin_ui.html controller to this Apps Script project.

Create one HTML file named "index" and paste the contents of index.html.

Enable the appsscript.json manifest in Apps Script Project Settings and paste
the manifest from this folder.

STEP 3: INITIALIZE THE INSTALLATION SECURELY
--------------------------------------------------------------------------------
1. In the Apps Script editor, select the function:
      initializeInstallation
2. Click Run.
3. Grant the requested Google permissions.
4. The function will:
   - Create/repair the Master Control schema.
   - Generate and store a random server-side cryptographic pepper in
     Script Properties.
   - Generate a one-time installation key.
5. Copy the one-time setup key from the execution result/log.

IMPORTANT:
- No default Super Admin is created.
- No default password is created.
- The one-time setup key is invalidated immediately after successful
  Super Admin creation.

STEP 4: DEPLOY WEB APP
--------------------------------------------------------------------------------
1. Click Deploy > New deployment.
2. Select Web app.
3. Configure:
   - Description: "FLINK Time Platform Production"
   - Execute as: Me
   - Who has access: Anyone in your Google Workspace domain
4. Deploy and copy the /exec URL.

The API now rejects mutating operations over GET. Mutating actions must use POST.

IDENTITY-BINDING REQUIREMENT:
- Keep execution as the deployer so staff do NOT need direct access to the
  Master/Workspace spreadsheets.
- Restrict the deployment to your Google Workspace domain.
- FLINK Time reads the server-observed Google Workspace email with
  Session.getActiveUser().getEmail() and requires it to match the FLINK
  account Email before issuing or accepting a WEB session.
- Do not deploy this production build as public "Anyone" access.

STEP 5: CREATE THE ROOT SUPER ADMIN
--------------------------------------------------------------------------------
1. Open the deployed Web App URL.
2. In Setup Step 1 enter:
   - The one-time installation key from Step 3.
   - Super Admin full name.
   - Username.
   - A strong password entered manually.
   - The Super Admin Email is bound automatically to the Google Workspace
     account currently opening the setup page.
3. Complete Step 1.

There are intentionally no pre-filled production passwords.

STEP 6: COMPLETE THE SETUP WIZARD
--------------------------------------------------------------------------------
Continue through:
- Company settings
- First workspace
- Optional Admin account
- Optional employee account
- Initial client/project/tasks
- Time rules
- Reporting/alert settings
- System check

Every account password must be supplied explicitly.
Every Admin/User account must also be created with its Google Workspace email.
That email is the identity binding used in addition to FLINK credentials.

STEP 7: GOOGLE SITES / DIRECT WEB ACCESS
--------------------------------------------------------------------------------
- Direct browser access: <YOUR_WEB_APP_URL>
- Google Sites: Insert > Embed > By URL > paste the Web App URL.

LEGACY CLIENTS / ADMIN CONTROLLER
--------------------------------------------------------------------------------
The Windows portable tracker and the old standalone Super Admin Controller are
NOT part of this stabilized modern API release yet.

Do not point the legacy controller at this deployment.
Do not rely on legacy actions such as:
- auth_handshake
- sync_batch
- entity_crud
- restore_database
- create_backup
- set_policy

They were intentionally removed from the deployable Apps Script API surface and
must be migrated to the modern authenticated API before production use.
