========================================================== 
ULTRA-ACCOUNT ENTERPRISE READY-TO-USE PACKAGE 
========================================================== 
This folder contains everything separated and ready to use: 
- 1_EMPLOYEE_PORTABLE_APP  : Give this folder to your employees to track time. 
- 2_SUPER_ADMIN_CONTROLLER : Open admin_ui.html to monitor and approve time. 
- 3_GOOGLE_BACKEND_SCRIPTS : Deploy to Google Sheets / Apps Script. 
- 4_CLIENT_PACKAGER_TOOL   : Run UltraPackager.exe to build pre-configured exes.
